# Castbox Downloader — selected design screens

Latest desktop collection: [DESKTOP_THEMES.md](DESKTOP_THEMES.md) — nine main desktop screens in both themes. The original nine-image collection below is retained as history.

Selected direction: warm editorial cream/espresso/orange (the second concept).
Scope: static UI designs only. No frontend behavior or backend is implemented by these images.
Generated using the built-in ImageGen tool with the selected concept attached to every call.

These nine images cover the main surfaces in representative themes and form factors. They are not a complete page × theme × platform or error-state matrix. Use INTERACTIONS.md for behavior, missing variants, and corrections.
