# Changelog

Notable project changes are recorded here. Dates reflect the work/release date; historical commit dates are not reconstructed.

## 0.1.0-preview.1 — 2026-10-09

First public source preview.

- Added Castbox catalog search, channel and episode browsing, and artwork retrieval through the desktop service boundary.
- Added local saved channels, playback history, listening queue, and settings persistence.
- Added native destination authorization, safe filename planning, duplicate policies, bounded workers, real download progress, pause/resume/cancel, and restart recovery.
- Added offline playback for completed local episodes, including seeking, playback speed, sleep timer, and queue controls.
- Added a polished desktop interface with light and dark themes.
- Documented macOS verification and the remaining visual, authentication, and cross-platform limitations.

This preview contains source code only. It does not include signed installers or a verified Windows/Linux build.
